# read-ipdf

## Purpose

Understand an iPDF as both a source document and a structured interactive artifact.

## Process

1. Read and validate the manifest.
2. Treat the embedded PDF as canonical source.
3. Load semantic anchors, scenes, provenance, and layer metadata.
4. Distinguish author content from generated interpretation.
5. Expose available scenes and primitive capabilities.
6. When answering questions, trace claims back to source anchors when possible.

## Output

A structured document model suitable for rendering, explanation, comparison, or further transformation.
